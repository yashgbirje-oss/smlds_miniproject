Viva explanation: Linear Regression learns a relationship between the house features and price. The model is trained on 80% of the rows and evaluated on the remaining 20%. MAE measures average absolute error, RMSE penalizes larger errors more, and R² measures the fraction of test-price variation explained by the model.

Problem Statement

House prices depend on several characteristics, including area, bedrooms, bathrooms, number of stories, parking, access to the main road, amenities and furnishing status. The aim is to train a regression model that estimates a property's price from these features.

Objectives

  • Explore the dataset and identify important patterns.
  • Check for missing values and duplicate records.
  • Preprocess numerical and categorical features.
  • Train a Linear Regression model to predict house prices.
  • Evaluate the model using MAE, RMSE and R² score.

Dataset Description

  • Dataset: Housing Prices Dataset (Housing.csv)
  • Source: Kaggle — Housing Prices Dataset
  • Expected rows: 545; columns: 13 (12 input features and 1 target).
  • Target variable: price.

The dataset does not contain named cities or neighbourhoods. It includes the categorical indicators mainroad and prefarea as limited location-related features.

5. Data Preprocessing

The uploaded dataset is checked for missing values and duplicate rows. The target price is separated from input features. Categorical columns are converted to numeric indicator columns using one-hot encoding. Numerical columns are passed through unchanged. A pipeline fits the encoder on training data to help prevent data leakage.

Show original notebook code
# Target and input features
X = df.drop(columns=["price"])
y = df["price"]

# Identify categorical and numerical input columns
categorical_features = X.select_dtypes(include=["object", "category"]).columns.tolist()
numerical_features = X.select_dtypes(include=np.number).columns.tolist()
print("Categorical features:", categorical_features)
print("Numerical features:", numerical_features)

preprocessor = ColumnTransformer(
    transformers=[
        ("categorical", OneHotEncoder(handle_unknown="ignore", drop="first"), categorical_features),
        ("numerical", "passthrough", numerical_features)
    ]
)

7. Model Building: Linear Regression

Linear Regression is selected as a baseline regression algorithm because it is straightforward to understand and provides a useful starting point for predicting a continuous target such as house price.

Show original notebook code
model = Pipeline(steps=[
    ("preprocessor", preprocessor),
    ("regressor", LinearRegression())
])

model.fit(X_train, y_train)
y_pred = model.predict(X_test)
print("Model training completed.")
print("First 10 predictions:")
display(pd.DataFrame({
    "Actual Price": y_test.iloc[:10].to_numpy(),
    "Predicted Price": y_pred[:10]
}))

8. Model Evaluation

mae = mean_absolute_error(y_test, y_pred)

9. Results and Discussion

MAE is the average absolute prediction error in the dataset's price units. RMSE gives greater weight to larger errors. R² indicates the proportion of variation in the test-set prices explained by the model; a value closer to 1 generally indicates a better fit.

Use the actual output from your run in your report. Results depend on the selected dataset, split and model. This dataset has limited location information and does not include factors such as exact neighbourhood, property age or current market conditions, so predictions should be treated as educational estimates rather than real-estate valuations.

10. Conclusion

This project uses the Housing Prices dataset to build a Linear Regression model for house price prediction. Exploratory analysis examines price distribution, the relationship between area and price, and average price across furnishing categories. Categorical features are one-hot encoded and the data is split into training and testing sets. Model performance is assessed using MAE, RMSE and R² score. Future improvements could include testing Random Forest Regression, tuning model parameters and using a dataset with more detailed location and property information.
