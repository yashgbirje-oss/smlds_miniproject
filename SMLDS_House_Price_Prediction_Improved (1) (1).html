1. Preprocessing & Regression Pipeline Code 
import pandas as pd
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import OneHotEncoder
from sklearn.pipeline import Pipeline
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score

# Load Housing dataset
df = pd.read_csv("Housing.csv")

# Separate features and target
X = df.drop(columns=["price"])
y = df["price"]

categorical_features = X.select_dtypes(include=["object", "category"]).columns.tolist()
numerical_features = X.select_dtypes(include=np.number).columns.tolist()

# ColumnTransformer handles one-hot encoding without data leakage
preprocessor = ColumnTransformer(
    transformers=[
        ("cat", OneHotEncoder(drop="first", handle_unknown="ignore"), categorical_features),
        ("num", "passthrough", numerical_features)
    ]
)

# 80:20 Train/Test Split
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.20, random_state=42)

# Fit pipeline
model = Pipeline(steps=[
    ("preprocessor", preprocessor),
    ("regressor", LinearRegression())
])
model.fit(X_train, y_train)

# Evaluation
y_pred = model.predict(X_test)
print(f"MAE:  ₹{mean_absolute_error(y_test, y_pred):,.2f}")
print(f"RMSE: ₹{np.sqrt(mean_squared_error(y_test, y_pred)):,.2f}")
print(f"R² Score: {r2_score(y_test, y_pred):.4f}")
🎓 Mini Project Viva Q&A Cheat Sheet
Common questions asked during project examinations and defenses
Q1. Why do we use OneHotEncoder with drop='first'?
Dropping the first category (e.g., creating 1 dummy column for a binary yes/no feature instead of 2) prevents perfect multicollinearity, commonly known as the Dummy Variable Trap. If both columns were kept, their sum would equal 1, making the feature matrix singular and coefficients unstable in Linear Regression.
Q2. What is the fundamental difference between MAE and RMSE?
Mean Absolute Error (MAE) measures the average absolute magnitude of errors linearly. Root Mean Squared Error (RMSE) squares each error before averaging and taking the root, thereby assigning disproportionately heavier penalties to large outliers. An RMSE significantly higher than MAE indicates occasional large prediction mistakes.
Q3. What does an R² score of 0.653 signify?
The coefficient of determination (R²) indicates that 65.3% of the variation in house prices is explained by our 12 input features. The remaining ~35% of variance stems from unobserved parameters such as specific neighborhood, proximity to transit, property age, and architectural finish.
Q4. How do you check if Linear Regression assumptions are satisfied?
We plot the Residuals vs. Fitted values. If residuals are randomly scattered around zero with constant spread across all price levels, the assumption of homoscedasticity holds. In our dataset, higher-priced luxury homes show slightly wider residual variance.
Q5. Why did Gradient Boosting perform slightly better than Linear Regression?
Gradient Boosting combines an ensemble of shallow decision trees that can capture non-linear feature interactions (such as the compounded effect of large area + AC + preferred location) without requiring explicit interaction terms.
